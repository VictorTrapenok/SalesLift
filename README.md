# SalesLift — аналитика звонков для отдела продаж

**Разверните за одну команду. Работает на вашем сервере — записи разговоров
никуда не уходят.**

SalesLift — мультитенантный SaaS для анализа телефонных разговоров отдела
продаж. Загружайте записи звонков, получайте расшифровки и разбор: как менеджер
вёл разговор, что упустил, где потерял клиента.

---

## Запуск

Нужен только **Docker**.

```bash
git clone <url> SalesLift && cd SalesLift && make up
```

Откройте **http://localhost:8000** — и зарегистрируйте компанию.

Всё. Ни конфигов, ни файлов настроек, ни базы данных руками. Первый
зарегистрировавшийся становится администратором и сразу попадает в кабинет.

```bash
make logs    # что происходит внутри
make down    # остановить
make reset   # остановить и удалить все данные
```

> ⚠️ **Образ ещё не опубликован**, поэтому `make up` пока собирает его локально
> — это несколько минут и требует доступа к реестрам npm и PyPI. Публикация в
> ghcr.io готовится ([дорожная карта](ROADMAP.md)); после неё команда станет
> тем, чем задумана: скачал и запустил за минуту.
>
> Пока образа нет, для ознакомления надёжнее путь из
> [docs/development.md](docs/development.md) — он проверен и работает.

## Что умеет

### Мультитенантность

Одна установка обслуживает сколько угодно компаний. Данные каждой изолированы:
сотрудник одной компании физически не может получить данные другой. Изоляция
проверяется тестами на каждый сценарий доступа.

### Компания и сотрудники

- **Самостоятельная регистрация.** Компания заводится за одну форму, без
  участия администратора сервиса.
- **Кабинет компании** со списком сотрудников, настройками и профилями.
- **Роли**: администратор, менеджер, наблюдатель.
- **Простой вход** — только e-mail и пароль. Не нужно помнить, на каком
  поддомене живёт ваша компания: поддоменов нет вовсе, всё на одном адресе.

### Два языка

Русский и английский — включая сообщения об ошибках. Язык запоминается в
профиле сотрудника.

### Ваши данные остаются вашими

Разворачивается на вашем сервере или в вашем кластере. Записи звонков и
расшифровки не покидают ваш контур.

### Анализ звонков

Загрузка записей, расшифровка и разбор разговоров — **в разработке**, см.
[дорожную карту](ROADMAP.md).

## Развёртывание в кластере

Для промышленной эксплуатации — Kubernetes или k3s:

```bash
helm install saleslift oci://ghcr.io/salehelper/charts/saleslift \
  --namespace saleslift --create-namespace \
  --set ingress.host=saleslift.example.com
```

По умолчанию чарт поднимает и базу — этого достаточно, чтобы начать работать.
Для промышленной нагрузки подключите управляемую PostgreSQL:
`--set postgresql.enabled=false --set externalDatabase.host=...`

> Helm-чарт готовится, см. [дорожную карту](ROADMAP.md). Сейчас доступен
> запуск через Docker.

## Технологии

Python 3.13 · FastAPI · GraphQL · PostgreSQL 18 · TypeScript · React 19 ·
Ant Design · Docker · Kubernetes

Без Redis, без брокеров сообщений, без внешних зависимостей: чем меньше
подвижных частей, тем меньше поводов не запуститься.
