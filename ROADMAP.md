# Дорожная карта

Что уже работает, что в работе и что дальше. Обновляется по мере готовности.

## Готово

Всё перечисленное покрыто тестами и проверено запуском.

### Компании и сотрудники

- [x] Регистрация компании. Первый зарегистрировавшийся становится администратором.
- [x] Вход по e-mail и паролю. Компания определяется по e-mail — поля «компания»
      в форме нет ([почему](docs/adr/0001-tenant-resolution.md)).
- [x] Роли: администратор, менеджер, наблюдатель.
- [x] Мультитенантность: каждый запрос к данным скоупится компанией явно.

### Платформа

- [x] GraphQL API со строгой типизацией и локализованными ошибками.
- [x] Схема БД, миграции, мягкое удаление.
- [x] Интерфейс: вход, регистрация, каркас кабинета, ru/en.
- [x] Кодогенерация типов фронтенда из схемы бэкенда: рассинхрон ломает сборку.

## В работе

- [ ] **Страницы кабинета.** Список сотрудников, настройки компании и профиль
      (пароль, «о себе») сейчас заглушки: рендерят заголовок. Резолверов под
      ними пока нет.
- [ ] **Воркер фоновых задач.** Таблица очереди и модель есть, планировщик — нет.
- [ ] **Публикация образа в ghcr.io.** Dockerfile и compose написаны, но образ
      ещё не опубликован, поэтому `make up` собирает его локально вместо того,
      чтобы скачать. Сборку пока не удалось проверить end-to-end: в среде
      разработки реестр npm недоступен изнутри контейнера. Проверяется вместе с
      настройкой CI, где сборка идёт на чистой машине.
- [ ] **e2e-тесты** на Playwright.
- [ ] **CI/CD** на GitHub Actions: сборка, тесты, публикация образа в ghcr.io.
- [ ] **Helm-чарт** для развёртывания в k3s.

## Дальше

### Домен звонков

Основная функциональность продукта. Каркас платформы существует, чтобы её
принять.

- [ ] Загрузка записей звонков.
- [ ] Хранилище файлов: S3 или локальная папка за одной абстракцией.
- [ ] Транскрибация в фоне.
- [ ] Аналитика: разбор разговора, выводы, метрики.
- [ ] Подключение записей из CRM.

### Платформа

- [ ] Приглашение сотрудников по ссылке (сейчас администратор задаёт пароль
      напрямую).
- [ ] Подтверждение e-mail и сброс пароля. Формы токенов заложены, отправки
      писем нет.
- [ ] Журнал действий.
- [ ] Postgres RLS как дополнительный слой изоляции поверх текущей дисциплины
      явного `tenant_id`.
